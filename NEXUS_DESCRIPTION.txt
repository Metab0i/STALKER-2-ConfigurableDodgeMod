[size=4][b]Description[/b][/size][size=3][color=#D4D4D8]
Configurable Dodge Mod adds a stamina-based dodge to S.T.A.L.K.E.R. 2. Hold a movement key and press the dodge button (Left Alt by default) - or double-tap your dodge keys - and Skif dodges left, right or back, camera-relative. Keys and forces are configurable live; no MCM needed.

Two builds, same behaviour: a [b]UE4SS (Lua)[/b] script and a [b]DLL (C++)[/b] version that compiles the logic and uses UE4SS only as a loader. Pick one.[/color][/size]

[size=4][b]Installation[/b][/size][size=3][color=#D4D4D8]
[i]Requires an existing update 2.1 UE4SS installation.[/i]

[b]UE4SS build[/b]
[b]1.[/b] Copy [b]ConfigurableDodgeMod[/b] into [/color][/size][code]...\ue4ss\Mods\[/code][size=3][color=#D4D4D8]
[b]2.[/b] Add to [b]ue4ss\Mods\mods.txt[/b]: [/color][/size][code]ConfigurableDodgeMod : 1[/code][size=3][color=#D4D4D8]

[b]DLL build[/b]
[b]1.[/b] Copy [b]ConfigurableDodgeNative[/b] into [/color][/size][code]...\ue4ss\Mods\[/code][size=3][color=#D4D4D8]
[b]2.[/b] Add to [b]ue4ss\Mods\mods.txt[/b]: [/color][/size][code]ConfigurableDodgeNative : 1[/code][size=3][color=#D4D4D8]

[b]3.[/b] Launch the game. Uninstall by deleting the folder and its mods.txt line.[/color][/size]

[size=4][b]Configuration[/b][/size][size=3][color=#D4D4D8]
Edit the mod's ini ([b]ConfigurableDodgeMod.ini[/b] for the UE4SS build, [b]ConfigurableDodge.ini[/b] for the DLL build) and save. Changes apply live within ~2 seconds - no setup tool, no restart. Every key is documented in the ini comments.

[b]Modality[/b] - [code]button[/code] (hold a movement key + press the dodge button) or [code]doubletap[/code]. [b]ButtonKey[/b] accepts any bindable key name, a VK hex code ([code]0x58[/code]) or a mouse button; default [b]Left Alt[/b]. [b]DoubleTapLeft / Right / Back[/b] default [b]Z / C / S[/b], window [b]0.155 s[/b]. [b]SideHorizontal / SideVertical[/b] and [b]BackHorizontal / BackVertical[/b] set the forces in cm/s. [b]StaminaCost[/b] defaults to [b]15[/b]. [b]EnergyDrinkEffect[/b] makes dodges free during the game's brief no-drain window after a drink ([b]4.5 s[/b]).

The DLL build adds [b]Cooldown[/b], [b]RequireStamina[/b], [b]RequireCursorFree[/b] and [b]Log[/b].

Default controls: hold [b]A / D / S[/b] and press [b]Left Alt[/b]. Forward-only movement does not dodge; low stamina and open menus/dialogs block dodges.[/color][/size]
