[size=4][b]Description[/b][/size][size=3][color=#D4D4D8]
Configurable Dodge Mod adds a stamina-based dodge to S.T.A.L.K.E.R. 2. Hold a movement key and press the dodge button (Left Alt by default) - or double-tap your dodge keys - and Skif dodges left, right or back, camera-relative. Every key and force value is configurable live; no MCM needed.[/color][/size]

[size=4][b]Installation[/b][/size][size=3][color=#D4D4D8]
[i]Full package (no UE4SS yet):[/i] copy the zip contents into
[/color][/size][code]Stalker2\Binaries\Win64\[/code][size=3][color=#D4D4D8]
then launch the game.

[i]Mod-only package (UE4SS installed):[/i]
[b]1.[/b] Copy [b]ConfigurableDodgeMod[/b] into
[/color][/size][code]...\ue4ss\Mods\[/code][size=3][color=#D4D4D8]
[b]2.[/b] Add to [b]ue4ss\Mods\mods.txt[/b]:
[/color][/size][code]ConfigurableDodgeMod : 1[/code][size=3][color=#D4D4D8]
[b]3.[/b] Launch the game.[/color][/size]

[size=4][b]Configuration[/b][/size][size=3][color=#D4D4D8]
Run [b]Setup.bat[/b] in the mod folder, or edit [b]ConfigurableDodgeMod.ini[/b]. Changes apply live within ~2 seconds.[/color][/size]

[list]
[*][size=3][color=#D4D4D8][b]Modality[/b] - [code]button[/code] (hold a movement key + press the dodge button) or [code]doubletap[/code] (double-tap keys). One is active.[/color][/size][/*]
[*][size=3][color=#D4D4D8][b]ButtonKey[/b] - the dodge button. Any key works: letters, F-keys, arrows, modifiers (Left Alt / Ctrl / Shift) and mouse buttons. Default [b]Left Alt[/b].[/color][/size][/*]
[*][size=3][color=#D4D4D8][b]DoubleTapLeft / Right / Back[/b] - double-tap keys. Default [b]Z / C / S[/b].[/color][/size][/*]
[*][size=3][color=#D4D4D8][b]DoubleTapWindow[/b] - max seconds between taps. Default [b]0.195[/b].[/color][/size][/*]
[*][size=3][color=#D4D4D8][b]SideHorizontal / SideVertical[/b] - side dodge force (cm/s). Default [b]650 / 500[/b].[/color][/size][/*]
[*][size=3][color=#D4D4D8][b]BackHorizontal / BackVertical[/b] - back dodge force (cm/s). Default [b]900 / 200[/b].[/color][/size][/*]
[*][size=3][color=#D4D4D8][b]StaminaCost[/b] - stamina per dodge. Default [b]20[/b] (vanilla jump).[/color][/size][/*]
[/list]

[size=3][color=#D4D4D8]
[b]Setup.bat[/b] captures keys live - press the key to bind it. Option [b]3[/b] at the modality prompt resets all settings to defaults.

Default controls: hold [b]A / D / S[/b] and press [b]Left Alt[/b]. Forward-only movement does not dodge; low stamina and open menus/dialogs block dodges.[/color][/size]
