[size=4][b]Description[/b][/size][size=3][color=#D4D4D8]
Configurable Dodge Mod adds a proper dodge to S.T.A.L.K.E.R. 2. Double-tap a movement key and Skif hops out of the way - left, right or backwards, relative to wherever you are looking. Every force value and every keybind is configurable live in the Mod Configuration Menu, and each dodge costs stamina through the game's own vitals system (same cost as a vanilla jump), so it plays by the Zone's rules instead of being a free escape button.

This is a from-scratch rebuild of the classic Dodge mod concept for game update 2.0+, implemented as an UE4SS script mod.[/color][/size]

[size=4][b]Installation instructions[/b][/size][size=3][color=#D4D4D8]
[i]Option A - "full" package (recommended if you do not have UE4SS yet):[/i]
[b]1.[/b] Copy the contents of the zip into your game's[/color][/size]
[code]S.T.A.L.K.E.R. 2 Heart of Chornobyl\Stalker2\Binaries\Win64\[/code]
[size=3][color=#D4D4D8]folder (the one containing Stalker2-Win64-Shipping.exe). This installs a UE4SS runtime pre-configured for STALKER 2 plus the mod.
[b]2.[/b] Launch the game. Done.

[i]Option B - "mod-only" package (you already have UE4SS):[/i]
[b]1.[/b] Copy the [b]ConfigurableDodgeMod[/b] folder into[/color][/size]
[code]S.T.A.L.K.E.R. 2 Heart of Chornobyl\Stalker2\Binaries\Win64\ue4ss\Mods\[/code]
[size=3][color=#D4D4D8][b]2.[/b] In [b]ue4ss\Mods\mods.txt[/b], make sure there is a line:[/color][/size]
[code]ConfigurableDodgeMod : 1[/code]
[size=3][color=#D4D4D8][b]3.[/b] Launch the game.

[i]Basic use:[/i] double-tap [b]Z[/b] to dodge left, [b]C[/b] to dodge right, [b]S[/b] to dodge backwards.[/color][/size]

[size=4][b]Main features[/b][/size]
[list]
[*][size=3][color=#D4D4D8]Double-tap dodges in three directions (left / right / back), camera-relative[/color][/size][/*]
[*][size=3][color=#D4D4D8]Separate horizontal and vertical force values for side dodges and back dodges[/color][/size][/*]
[*][size=3][color=#D4D4D8]Stamina cost per dodge (vanilla jump cost by default) - applied through the game's native vitals API so the HUD updates properly[/color][/size][/*]
[*][size=3][color=#D4D4D8]Dodging is blocked when you lack the stamina for it (toggleable)[/color][/size][/*]
[*][size=3][color=#D4D4D8]All values configured via a plain ini file (interactive Setup.bat included)[b]: the "Force" category (Side Dodge Horizontal/Vertical Force, Back Dodge Horizontal/Vertical Force, Jump Stamina Cost) and the "Keybinds" category (Double-Tap Dodge Left/Right/Back Key)[/color][/size][/*]
[*][size=3][color=#D4D4D8]ini changes apply live in ~2 seconds - no restart needed; mid-combat[/color][/size][/*]
[*][size=3][color=#D4D4D8]No MCM needed at all - plain ini config, zero dependencies beyond UE4SS[/color][/size][/*]
[/list]
